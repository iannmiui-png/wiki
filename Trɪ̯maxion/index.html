Trɪ̯maxion

From Esolang
Jump to navigation Jump to search

Trɪ̯maxion is a TernLSB derivative language. The name is a reference to Buckminster Fuller's Dymaxion concept, but it is trinary. Like TernLSB the programs are stored in an image but program images are specified to what is called "positive feedback"[1] format.

In its simplest form, Fuller's Dymaxion concept is that rational action in a rational world, in every social and industrial operation, demands the most efficient over-all perfomance per units of input. A Dymaxion structure, thus, would be one whose performance yielded the greatest possible efficiency in terms of the available technology."[2]

The Trɪ̯maxion concept is by extension a structure who's performance yields the greatest possible efficiency in terms of technology which is not yet available; hence (in this example) it is an esoteric programming language.

Memory model

Programs are stored in the form of kontakion images. The positive feedback format nomenclature stems from the fact that the encoded programs can be constructed from the container image. Given that kontakions are a form of memory image this also serves as the memory model and makes this language part of the 9_trits,_19683_trytes family.
