掛軸key (pronounced "kakejiku key") is an esoteric programming language in the string-rewriting paradigm. Programs are a formed by matching a key to a script mandala (a "kakejiku"). In essence the programs here are locks so a ConstantLanguage() is used to enumerate the system.

A kakejiku

The first line contains a magic number (generally "P2" or "P5") followed by a program description.
P2 <-> P5
# This line is the program description. A series of programs is presented to attempt to describe a sequential replacement system as if it were a key being turned in a lock. A key here is described as part of a kakejiku (Kanji:掛軸) or a "hung script."
