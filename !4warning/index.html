Varnier scale





The Varnier scale is used as a ruler and can be rendered in graphing software. K describes a set of relations on x and y.

sin(10πx)>0;
1<=y<=2;
0<=x<=1;
sin(12πx)<0;
0<=y<=1;
0<=x<=1;
sin;(10πx)=0;
sin;(11πx)=0;
0<=y;<=2
0<x<1;

put

To perform the principal function (print):

  1. !4warning compares a portable bitmap file with a P1 magic header against K.
  2. If k = K print 4.
  3. else: intervals = abs(k - K) // 17
  4. print(chr(intervals % 128))

You could print any other ascii by evaluating the set of files given here https://raw.githubusercontent.com/iannmiui-png/wiki/refs/heads/main/!4warning/pbms or a zipped folder containing each bitmap can be found here. (Github)
