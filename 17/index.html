Overview

In 17 the number 17 is defined as ι+ι=17.

Operations

There is only addition of ι (known as lower-case iota.)

Example programs

A program is simply a unary string of ι symbols, so a golfed "Hello, World!" (A program which only prints the letter H)

or alternatively two hundred forty billion, five hundred eighteen million, six hundred ninety-two thousand, eight hundred seventy-eight lower-case iotas.
